## 1. Excel 导入中心

### 1.1 支持的导入类型

```text
商品导入、SKU 导入、供应商导入、客户导入
仓库导入、库位导入
采购订单导入、销售订单导入
初始化库存导入
```

### 1.2 导入流程（完整向导）

**禁止**做成简单的"选择文件 → 导入"。必须实现完整流程：

```text
下载模板
→ 上传 Excel
→ 读取（后端解析）
→ 字段校验
→ 数据校验
→ 错误提示（逐行展示）
→ 预览（解析后的结构化数据）
→ 确认导入
→ 批量写入（事务/分批）
→ 导入结果（成功数/失败数/错误明细）
```

### 1.3 校验规则

必须检查：

```text
必填字段
数据类型
日期格式
数字格式
SKU 是否存在
仓库是否存在
库位是否存在
供应商是否存在
重复数据（文件内重复）
编码重复（与数据库重复）
数量合法性（> 0、整数/小数规则）
金额合法性（>= 0、精度）
```

### 1.4 错误提示与错误文件

错误行必须精确定位并展示，例如：

```text
第 12 行：SKU 不存在
第 15 行：数量不能为负
```

支持导出**错误 Excel**（原数据 + 错误原因列），让用户修复后重新导入。

## 2. Excel 导出

### 2.1 支持导出的核心列表

```text
商品、SKU、供应商、客户、仓库、库位
采购订单、入库单、出库单
库存、库存流水、调拨单、盘点单、质检单、异常单、报表
```

### 2.2 导出范围

```text
当前页导出
选中数据导出
全部导出
按筛选条件导出
按时间范围导出
```

### 2.3 导出质量要求

导出的 Excel 必须包含：

```text
标题、导出时间、导出人、查询条件
列标题、数据、总计、合计
分页/分组信息
```

格式要求：

- 数字格式正确（数量千分位）
- 日期统一（YYYY-MM-DD HH:mm:ss）
- 金额统一（¥ 1,234.56 或纯数值 + 单元格格式）
- **不要把所有内容导出成字符串**——数值列使用数值单元格类型，日期列使用日期类型。

## 3. 大数据量导出

数据量大时**禁止**：一次性查询全部数据库数据 → 内存生成 Excel。

必须支持：

```text
分批读取（游标/分页流式查询）
流式导出（流式写出 Excel，不整表驻留内存）
异步导出（大任务后台执行）
导出任务（任务表记录）
导出进度（如：处理中 35%）
文件有效期（过期自动清理）
下载记录（谁在何时下载过）
```

标准异步导出体验：

```text
创建导出任务 → 任务列表显示"处理中 35%" → 完成 → 下载
```

后台可查看：导出任务、文件、创建人、时间、状态。

## 4. 导入/导出任务化（数据中心）

建立统一的**数据中心**页面：

```text
导入任务
导出任务
打印任务
```

任务记录字段：

```text
任务类型、业务模块、创建人
开始时间、结束时间
数量、成功数量、失败数量
文件（产物下载）
状态（排队中/处理中/成功/部分成功/失败）
```

---

## 5. 异常恢复与文件管理

- "Excel 已生成但下载失败"：文件保留有效期，用户可随时重新下载。
- 导出文件不能永久堆积，支持：

```text
文件过期（按有效期自动标记）
自动清理（定时任务清理过期文件）
手动删除
下载记录
```

---

## 6. 导入一致性约束

1. 初始化库存导入属于高危操作：必须走审批或二次确认，导入产生库存流水（业务类型=初始化导入）。
2. 批量写入采用分批事务：单批失败不影响已完成批次，失败明细进入导入结果。
3. 导入执行幂等：同一导入任务不重复执行（任务状态守卫）。

## 7. 文件中心

建立统一文件中心，所有业务附件/产物文件统一登记：

记录字段：

```text
文件名、文件类型、大小、上传人、上传时间
业务模块、关联单据
```

支持：

```text
下载、预览、删除、权限控制（按模块/数据权限过滤可见文件）
```

文件存储路径由服务端生成（api.md §5 上传安全）。
