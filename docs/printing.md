# StockFlow 打印中心规范

> 版本：v1.0 ｜ 关联文档：[excel.md](excel.md)、[frontend.md](frontend.md)

---

## 1. 打印中心

系统必须建立独立的**打印中心**模块（不是散落在各页面的 window.print）。

### 1.1 支持的打印对象

```text
商品标签、SKU 标签、条码标签、库位标签
箱码、托盘码
入库单、收货单、质检单、上架单
拣货单、复核单、打包单、出库单、发货单
调拨单、盘点单
```

### 1.2 打印任务

打印统一走任务模型（与导入/导出任务并列，见 excel.md §4）：

```text
创建打印任务 → 选择模板 → 预览 → 执行打印 → 记录打印日志
```

记录：打印人、打印时间、模板、数据量、打印结果。

---

## 2. 打印模板

**禁止把打印 HTML 写死**。建立打印模板体系：

```text
打印模板
├── 模板名称
├── 类型（标签/单据/报表）
├── 页面尺寸（A4/A5/热敏纸规格）
├── 标签尺寸
├── 字体
├── 字段（可配置的数据字段绑定）
├── 条码（Code128 等）
├── 二维码（QR Code）
├── 图片（Logo 等）
└── 状态（启用/停用）
```

模板示例——库位标签：

```text
A-01-03-05

仓库：A仓
库区：成品区
货架：03
库位：05

[二维码]
```

模板支持新增、编辑、复制、停用；单据类模板包含页眉（公司名/单据名）、明细表、页脚（制表人/审核人/打印时间）。

---

## 3. 批量打印

支持：

```text
选中 100 个 SKU → 批量打印标签
```

以及：

```text
批量打印库位标签
批量打印拣货单
批量打印出库单
批量打印发货单
```

批量打印前必须显示影响数量并支持预览确认。

---

## 4. 二维码与条码

### 4.1 支持的码制

至少支持（与扫码解析端码制范围一致，见 scanner.md §5.1）：

```text
Code128（条码，默认推荐）
Code39、EAN-13、EAN-8、UPC
QR Code（二维码）
DataMatrix
```

业务层不强制要求所有条码为同一种，打印时按对象与模板配置选择码制。

### 4.2 可生成的码

```text
SKU 条码
库位二维码
箱码
托盘码
单据二维码
```

### 4.3 扫码直达业务

扫码后能够直接打开对应业务对象，例如：

```text
扫描库位二维码 → 自动进入该库位库存页面
扫描 SKU 条码 → 自动定位该 SKU
扫描单据二维码 → 自动打开该单据详情
```

统一扫码路由协议：码内容携带业务类型 + 业务 ID（或编码），由前端扫码入口统一解析分发（见 frontend.md §10）。

---

## 5. 打印预览

**禁止**点击按钮直接调起浏览器打印导致页面布局错乱。

必须实现打印预览流程：

```text
点击打印
→ 打开打印预览（独立预览层/页面）
→ 选择模板
→ 预览（真实数据渲染，所见即所得）
→ 打印
```

---

## 6. 打印技术要求

- 独立打印渲染层，与系统页面样式隔离（不受全局 CSS 影响）。
- 支持 A4、A5、热敏纸、标签纸多种纸张。
- 条码/二维码矢量或高分辨率渲染，确保扫码枪可识别。
- 中文字体正确渲染，长表格自动分页，多页保持页眉页脚。
- 打印记录入操作日志（谁、何时、用什么模板、打了什么）。
